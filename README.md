# Финансовый Аналитический Бэкенд

Приложение на Python для анализа и автоматической обработки финансовых транзакций из Excel-выгрузок. Проект предоставляет инструменты для генерации веб-отчётов, биржевых котировок, накопительных сервисов и комплексной аналитики расходов. Доступен как в виде консольного приложения, так и в виде REST API (FastAPI).

## 🛠 Технологический стек

* **Язык разработки:** Python 3.14+
* **Управление зависимостями:** Poetry
* **Анализ данных:** Pandas (чтение Excel, фильтрация, агрегация)
* **Веб-фреймворк:** FastAPI + Uvicorn (REST API и Swagger UI)
* **Работа с сетью:** Requests (интеграция со сторонними финансовыми API)
* **Тестирование:** Pytest + Pytest-cov (автоматические тесты и замер покрытия)
* **Качество кода:** Black (форматирование), Flake8 (линтер), iSort (сортировка импортов), Mypy (строгая типизация)

## 🚀 Функциональные возможности

### 1. Страница «Главная» (`src/views.py`)
Формирует комплексный JSON-ответ для фронтенда на основе переданной даты и времени:
* **Динамическое приветствие:** Автоматически рассчитывается по часам суток («Доброе утро», «Добрый день» и т.д.).
* **Аналитика по картам:** Группирует расходы по банковским картам, рассчитывает общие траты за месяц и начисленный кэшбэк (1% от суммы расходов).
* **Топ-5 транзакций:** Выводит 5 самых крупных операций за месяц, отсортированных по сумме.
* **Финансовые API:** Интегрируется с внешними биржами. Запрашивает живые курсы валют (через *ExchangeRate-API*) и имеет встроенные отказоустойчивые заглушки для котировок акций S&P500 из файла `user_settings.json`.

### 2. Сервисы (`src/services.py`)
* **Инвесткопилка:** Математическая модель накоплений. Округляет расходы в большую сторону до заданного шага (10, 50 или 100 ₽) и суммирует отложенную разницу за календарный месяц. Поддерживает работу с реальными банковскими выгрузками.
* **Простой поиск:** Поисковый движок, осуществляющий фильтрацию всех транзакций по ключевому слову в категориях или описании без учёта регистра.

### 3. Отчёты (`src/reports.py`)
* **Траты в рабочий/выходной день:** Рассчитывает и сравнивает средний чек расходов пользователя в будни (Пн-Пт) и выходные (Сб-Вс) за последние 3 месяца.
* **Декоратор сохранения (`@report_to_file`):** Автоматически перехватывает таблицы данных Pandas и сохраняет результаты анализа на диск в формате JSON с уникальным временным штампом.

## 💻 Установка и запуск

### 1. Клонирование и подготовка окружения
Убедитесь, что у вас установлен менеджер пакетов Poetry. В терминале проекта выполните:
```bash
# Установка всех зависимостей проекта
poetry install
```

### 2. Настройка конфигурации
* Задайте интересующие вас акции и валюты в файле `user_settings.json`.
* Создайте файл `.env` в корне проекта и укажите ваши персональные ключи (требуется для работы живых курсов валют):
```text
EXCHANGE_API_KEY=ваш_ключ_exchangerate_api
```

### 3. Запуск приложения
Для проверки работы сервисов и веб-страниц запустите главный модуль:
```bash
poetry run python -m src.main
```

## 🌐 API Endpoints (FastAPI)

Проект также доступен в виде REST API. После запуска сервера интерактивная документация (Swagger UI) доступна по адресу: `http://127.0.0.1:8000/docs`.

### Запуск сервера:
```bash
poetry run uvicorn src.api:app --reload
```

### Доступные эндпоинты:

| Метод | Эндпоинт | Параметры | Описание |
| :--- | :--- | :--- | :--- |
| GET | `/views/main` | `dt` (YYYY-MM-DD HH:MM:SS) | Главная страница: приветствие, карты, топ-5 транзакций, валюты, акции |
| GET | `/services/invest` | `month` (YYYY-MM), `limit` (10/50/100) | Сервис «Инвесткопилка» |
| GET | `/services/search` | `query` (строка) | Поиск по описанию и категории |
| GET | `/reports/workday` | `date` (DD.MM.YYYY, опционально) | Средние траты в рабочий/выходной день |

## 🧪 Тестирование и качество кода

### Запуск автоматических тестов:
Проект покрыт 13+ изолированными тестами для проверки математики, парсинга дат и граничных условий:
```bash
poetry run pytest
```

### Проверка покрытия кода тестами (Coverage):
```bash
poetry run pytest --cov=src
```

### Проверка стиля кода и линтинг:
```bash
poetry run isort .   # Сортировка импортов
poetry run black .   # Форматирование кода по PEP 8
poetry run flake8 .  # Проверка линтером
poetry run mypy .    # Статический анализ типов
```
